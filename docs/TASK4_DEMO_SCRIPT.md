2. **15–35s:** As `aster-procurement`, ask about approved fire-documented upholstery, suppliers and quoted prices; show `/knowledge/search` evidence and `/knowledge/ask` (only if it verifies).

5. **70–90s:** Briefly show fusion code, the GIN full-text index, unit tests and the distinction between verified citation integrity and semantic claim correctness. State that identity is simulated locally, not production-grade.
